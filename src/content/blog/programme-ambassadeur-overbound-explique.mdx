Le programme ambassadeur récompense les personnes qui font venir leurs amis à Overbound. Tu as un code personnel : chaque ami qui s'inscrit avec ce code te rapporte des points, et les points débloquent des récompenses, jusqu'au dossard gratuit.

## Comment gagner des points

- **1 point** par inscription au format OPEN avec ton code ;
- **2 points** par inscription au format RANKED avec ton code.

Si tu ne sais pas ce que sont OPEN et RANKED, lis [OPEN ou RANKED](/blog/post/open-vs-ranked-choisir-son-format).

Trois cas ne rapportent aucun point : t'inscrire toi-même avec ton propre code, une commande à 0 €, une inscription annulée. Si une inscription est remboursée ou annulée, les points qu'elle avait rapportés sont retirés.

## Les paliers de la saison 2027

| Points | Récompense |
|---|---|
| 1 | Un badge ambassadeur |
| 3 | Un code promo de -50 % |
| 5 | Un T-shirt Overbound |
| 8 | Un dossard OPEN offert |
| 12 | Une mise en avant sur les réseaux d'Overbound |
| 20 | Un dossard RANKED offert |
| 25 | Un pack média : photos et vidéos de l'événement |
| 30 | Le statut Ambassadeur Or |

Au-delà de 30 points, tu gagnes un dossard offert en plus tous les 5 points, sans plafond. Les paliers sont définis par l'équipe pour chaque saison : l'échelle à jour est toujours dans ton [espace ambassadeur](/ambassadors/dashboard).

## Combien de temps ça dure

Il n'y a pas de remise à zéro au 1er janvier. Le programme fonctionne par saison, et les points s'accumulent pendant toute la saison. Les récompenses gagnées doivent être réclamées avant la fin de la saison : la saison 2027 se termine le 31 décembre 2027. Passé cette date, une récompense non réclamée n'est plus disponible.

## Comment partager ton code

Depuis ton espace ambassadeur, le bouton « Partager » donne un lien du type `overbound-race.com/?ref=TONCODE`. Ton ami ouvre le lien, et ton code s'applique tout seul quand il s'inscrit. Il peut aussi saisir ton code à la main dans le tunnel d'inscription. Les étapes de l'inscription sont décrites dans [le guide d'inscription](/blog/post/guide-complet-inscription-overbound).

La page [ambassadeurs](/ambassadors) liste ceux qui ont accepté d'apparaître publiquement. Pour rejoindre le programme, écris à l'équipe via la page [contact](/contact). Si tes amis viennent de la même entreprise, la page [entreprises](/entreprises) décrit la remise de groupe, à partir de 2 billets.
